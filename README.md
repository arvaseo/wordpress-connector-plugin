# Arva SEO Connector for WordPress

The free WordPress plugin that connects a WordPress site to [Arva SEO](https://arvaseo.com).

- **Install it:** in WordPress, open Plugins → Add New Plugin and search for **Arva SEO Connector**, or see https://wordpress.org/plugins/arvaseo-connector/
- **What it does:** https://arvaseo.com/features/wordpress/
- **Help:** [Connect your WordPress site](https://support.arvaseo.com/articles/connect-your-wordpress-site)

The plugin sends a site's plugin inventory and about 40 WordPress health checks to Arva SEO, once a WordPress administrator agrees to the exact list of fields. It receives drafts from Arva SEO's Content Studio, never beyond the publishing limit the site's administrator sets, and updates SEO titles and meta descriptions in Yoast SEO or Rank Math when an administrator allows it. Requests from Arva SEO are signed, and the site never sees an Arva SEO password.

The plugin's source is in `arvaseo-connector/`. Requires WordPress 6.5+ and PHP 8.1+.

## Security

Please report security issues privately through https://arvaseo.com/contact/ rather than in a public issue.
